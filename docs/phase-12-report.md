# المرحلة الثانية عشرة — ضمان الجودة والتحسين والإصدار 1.0.0

المرحلة الأخيرة من Kim (MyWallet). لم تُضف ميزات مالية جديدة؛ رُوجع المشروع
كاملًا واختُبرت الدورة المالية من البداية إلى النهاية، وأُصلحت المشكلات
المكتشفة دون إزالة أي سلوك عامل، وجُهّز بناء Flutter Web إنتاجي.

## المراجعة

رُوجعت طبقات المراحل 1–11: `Money` بوحدات `BigInt` ودقة صريحة، ومعرفات
العمليات و`applyOnce` الذري، والسجل المحاسبي غير القابل للتعديل الذي يُشتق
منه كل رصيد، وترحيلات القاعدة حتى الإصدار 11، وحماية حجوزات الادخار، والديون،
والاشتراكات، ودفتر أسعار التقييم، والتقارير ولوحة التحكم، والنسخ والاستعادة.
لا يوجد `double` في أي مجموع مالي؛ الكسور العائمة محصورة في أطوال أشرطة
التقدم والرسوم بعد قسمة `BigInt` محدودة.

## الأداء

| القياس (VM، 2000 عملية) | قبل | بعد |
|---|---|---|
| تحميل كل العمليات | ≈224 ms | ≈50 ms |
| إنشاء عملية واحدة | ≈98 ms | ≈42 ms |
| 2000 تحقق تاريخ | ≈95–165 ms | ≈2–12 ms |
| حجم كاش العمل دون إنترنت | 45.5 MiB / 42 ملفًا | 21.7 MiB / 28 ملفًا |

فحص الإصدار في Chrome على localhost (`docs/phase-12-browser-validation.json`):
أول إطار للتحميل الأول **1924 ms** بـ15 طلبًا و13.3 MiB، والتحميل دون شبكة
من الكاش **765 ms**. الأرقام تعتمد على الجهاز؛ تُستخدم للمقارنة لا كضمان.

## التحقق

- `flutter analyze`: لا مشكلات. `dart format --set-exit-if-changed`: نظيف
  (نُسّق ملفا اختبار قديمان بفروق مسافات فقط).
- `flutter test --concurrency=1 --test-randomize-ordering-seed=20261020`:
  **260 اختبارًا ناجحًا** بترتيب عشوائي (كان 241).
- بناء `flutter build web --release --no-web-resources-cdn --pwa-strategy=none`
  ثم `generate_offline.dart` ناجح (Wasm dry run ناجح أيضًا).
- `npm run test:release`: 8 فحوص ناجحة — بدء التشغيل، دورة مالية عبر الواجهة
  تبقى بعد إعادة التحميل، كاش العامل، إعادة التحميل دون شبكة، كل الصفحات
  الـ13 دون شبكة بعرض 320/768/1440، صفحة المسار المجهول، العربية الداكنة على
  الهاتف واللوحي، ولا أخطاء صفحة أو كونسول أو طلبات خارجية.
- انحدار المتصفح للمراحل السابقة على البناء نفسه: المرحلة الأولى، والمحافظ
  (15)، والعمليات (11)، والتحويلات (13)، ولوحة التحكم (9)، والتخطيط (11)،
  والادخار (11)، والديون (10)، والاشتراكات (12)، والتقارير (13)، والأمان (13):
  **كلها ناجحة**. صور وأدلة المراحل السابقة لم تُستبدل.
- صور الإصدار: `phase-12-dashboard-en.png` و`phase-12-wallets-ar-320.png`
  و`phase-12-dashboard-ar-320.png` و`phase-12-reports-ar-tablet.png`.

## حدود متبقية

- الفحص الآلي للمتصفح على Chrome فقط؛ Firefox وSafari وأجهزة iOS لم تُختبر.
- `main.dart.js` بنحو 5.1 MiB و`NotoSans.ttf` بنحو 2 MiB؛ لم تُقلّص الخطوط
  لأن المستخدم يكتب أسماء بأي لغة، ولم يُعتمد بناء Wasm لأنه يحتاج تحققًا
  منفصلًا على المتصفحات غير Chromium.
- الكتابة المالية ما زالت تقرأ سجل المحفظة خطيًا (≈42 ms عند 2000 عملية على
  VM)؛ مقبول للاستخدام الشخصي، والفهرسة خارج نطاق هذه المرحلة.
- التقارير تقرّب كل قيد إلى عملة العرض قبل الجمع (سياسة موثقة منذ المرحلة 10).
- لم يُعد بناء APK في هذه المرحلة؛ تقرير Android السابق يبقى مرجع ذلك البناء.
- سياسة تنفيذ PowerShell على هذا الجهاز تمنع تشغيل `build_web.ps1` مباشرة؛
  استخدم `-ExecutionPolicy Bypass -File` أو أوامر البناء المباشرة.
- الفرع `feature/quality-release` محلي؛ لا رفع ولا دمج في main دون طلب.
