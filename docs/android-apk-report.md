# Android APK — المراحل حتى الثامنة

أنشئ بناء Android أصلي من نفس واجهة Flutter والميزات المالية الموجودة.
معرف الحزمة `com.mahmoudsalem.kim`، الاسم Kim، الإصدار `0.1.0+1`،
Android 7.0/API 24 فأحدث، وبناء شامل لـ arm64-v8a وarmeabi-v7a وx86_64.
أيقونة المحفظة الزمردية مضافة كـ Android vector drawable.

التخزين أصبح باختيار مشروط حسب المنصة: الويب يحتفظ بنفس IndexedDB
واسم `mywallet`؛ أندرويد يستخدم Sembast IO في مجلد دعم التطبيق الخاص،
عبر `path_provider`، بالملف `mywallet.db`. لا حاجة لتسجيل دخول أو صلاحية
تخزين عامة. بيانات التطبيق على الهاتف مستقلة عن بيانات متصفح الكمبيوتر.

البناء بـ `flutter build apk --release`، والتحقق بـ Android apksigner
وaapt. النسخة موقعة بمفتاح Android Debug المحلي للتثبيت والتجربة، وليست
إعداد نشر متجر؛ مفتاح إنتاج وتوزيع متجر يحتاجان إعدادًا مستقلًا.

مصانع التخزين، وتوليد كاش الموارد المحلية.

إعدادات المحاكاة الافتراضية أو تثبّت برامج تشغيل للنظام. البناء والتوقيع
