# المرحلة الحادية عشرة — الإعدادات والأمان والنسخ الاحتياطي

## السلوك المكتمل

صفحة إعدادات مشتركة التصميم بالعربية والإنجليزية، مع اللغة والثيم
والانتقال إلى إدارة عملة العرض الافتراضية وأسعارها الموثقة. لا يتغير
مبلغ مالي أصلي عند تغيير عملة العرض. إخفاء الأرصدة العام إعداد محفوظ
يُطبّق على تدفق المحافظ الذي تستخدمه الصفحات المالية، دون كتابة أعلام
إخفاء المحافظ الفردية؛ عند إلغائه تعود حالة كل محفظة كما كانت.

قفل اختياري بـPIN من 6 إلى 12 رقمًا، مع تعيين وتغيير وإزالة تتطلب
الرمز الحالي، وزر قفل في الشريط والإعدادات. جلسة جديدة أو إعادة تحميل
تتطلب فتح القفل إذا كان PIN مفعّلًا. العودة من الخلفية تتطلب الرمز أيضًا؛
نافذة اختيار/حفظ ملف يفتحها التطبيق نفسه مستثناة لأنها إجراء نظام تابع
لعملية النسخ. شاشة القفل لا تركّب الملاح المالي خلفها، وتملك طبقة إدخال
وملاحًا مستقلًا لحقول PIN وحوار استعادة النسخة.

الرمز لا يخزّن كنص: PBKDF2-HMAC-SHA256 بـ120000 دورة وملح عشوائي
16 بايت. تُحفظ محاولات الفشل وفترة انتظار 30 ثانية بعد خمس محاولات،
وتُقارن نتيجة ثابتة الطول. تعديل متزامن لبيانات الرمز يرفض الإجراء بدل
الكتابة فوق تغيير آخر.

هذا **قفل واجهة محلي** وليس تشفيرًا لقاعدة بيانات الجهاز أو المتصفح،
ولا حدًا أمنيًا أمام مالك الجهاز أو أدوات المطور أو تعديل ساعة الجهاز
والتخزين. التفويض في الذاكرة خاص بجلسة التطبيق؛ لا ندّعي قفلًا مركزيًا
فوريًا لكل نافذة أخرى مفتوحة. مسح بيانات الموقع يحذف البيانات. لا خدمة
خلفية لاسترجاع الرمز. هذه الحدود موضحة داخل الإعدادات وشاشة القفل.

## صيغة النسخ والتشفير

ملف `.kim` بتنسيق 1 يضم لقطة متسقة داخل معاملة واحدة من جميع مخازن
العمل المالية: المحافظ والقيود والعمليات والتحويلات والتصنيفات والميزانيات
والأهداف والمساهمات والديون وأحداثها والاشتراكات وإيصالات استحقاقها
والعملات وأسعارها والإعدادات وحالة الإشعارات وبيانات تحقق PIN وإيصالات
العمليات الأصلية. تبقى المعرفات والعلاقات والعملات والدقة والمبالغ النصية
الأصلية دون إعادة توليد. لا تضم النسخة ملفات بناء التطبيق أو كاش المتصفح
أو أذونات النظام ولا نسخة الرجوع المحلية بصورة متكررة.

الملف العادي يحمل SHA-256 لاكتشاف التلف؛ **ليس توقيعًا يثبت هوية
صاحب الملف**، ويمكن تعديل ملف عادي وإعادة حساب بصمته. لذلك تُطلب نسخة
من مصدر موثوق، ويُفحص أيضًا الشكل والمنطق والعلاقات قبل الاستعادة.
الملف العادي يكشف البيانات المالية وبيانات تحقق PIN، وهذا تحذير ظاهر.

خيار التشفير يستخدم AES-256-GCM مع اشتقاق مفتاح PBKDF2-HMAC-SHA256
بـ210000 دورة، وملح جديد 16 بايت وnonce جديد 12 بايت ووسم تحقق 16
بايت لكل ملف. بيانات التنسيق الثابتة تدخل التوثيق AAD. لا تُحفظ كلمة
مرور الملف؛ طولها المقبول 10–4096 وحدة نصية ويُطلب تأكيدها عند الإنشاء.
لا يمكن استرجاع كلمة مرور مفقودة. بيانات الاشتقاق غير المعروفة أو عدد
دورات معدّل تُرفض قبل إجراء اشتقاق مكلف.

الحد 32 MiB للملف و100000 سجل. قراءة الملف تستخدم تدفقًا محدودًا
بدل تحميل ملف غير محدود. الويب ينزّل الملف، والمنصات الأصلية تستخدم
نافذة النظام لاختيار موقع حفظه؛ إلغاء الحفظ قبل الاستبدال يلغي الاستعادة.

## الاستعادة والحماية من الفقد

1. فك التشفير/التحقق من البصمة والتنسيق وإصدار البيانات. الإصدارات
   المدعومة للبيانات 8–11؛ الإصدارات الأقدم أو المستقبلية أو صيغة ملف
   غير معروفة ترفض صراحة دون استبدال البيانات.
2. رفض المخازن المجهولة والمكررة والمفاتيح المكررة والأشكال غير السليمة.
   الاستيراد داخل قاعدة ذاكرة منفصلة ثم ترقية البيانات إلى الإصدار 11.
3. تشغيل قارئات المجالات والتحقق من تسلسل الأرصدة وآثار المصروفات
   والتحويلات ورسومها وأحداث الديون والمساهمات والحجوزات والمراجع إلى
   المحافظ والتصنيفات وإيصالات الاستحقاق والإعدادات وبيانات PIN.
4. عرض تاريخ الملف وإصداره وعدد سجلاته، وتنبيه إن كان يتضمن PIN قديمًا؛
   كلمة مرور الملف لا تستبدل الرمز المحفوظ داخله. يلزم مربع تأكيد صريح.
5. خيار افتراضي لتنزيل نسخة **غير مشفرة** من البيانات الحالية قبل
   الاستبدال، مع تسمية واضحة. يمكن إلغاؤه؛ تبقى نسخة الرجوع المحلية
   التلقائية ضمن العملية الذرية في جميع الأحوال.
6. إعادة مقارنة اللقطة الحالية داخل معاملة الكتابة؛ أي تغيير مالي أو
   إعدادات أو أمان أثناء المعاينة يرفض الاستعادة ويستلزم معاينة جديدة.
7. حذف/كتابة مخازن البيانات ونسخة الرجوع وإيصال الاستعادة ذي البصمة
   ومعرف ثابت داخل معاملة واحدة. لا دمج للملفات ولا إعادة تسجيل حركات
   نقدية. فشل قبل الالتزام يعيد كل شيء؛ إعادة الطلب نفسه لا تعيد تطبيقه.
8. منع التفاعل أثناء الاستبدال وإيقاف معالجة الاشتراكات والإشعارات أثناء
   القفل والصيانة. إلغاء تنبيهات الجهاز القديمة، ثم إعادة إنشاء حاوية
   المزودات بالإعدادات المستعادة؛ معالجة المستحقات تبدأ عند إتاحة الجلسة
   الجديدة. بعد الالتزام لا يُعاد فتح الجلسة القديمة قبل تطبيق PIN الجديد.

تُحفظ نسخة رجوع محلية واحدة فقط، تُستبدل بكل استعادة. يمكن مراجعتها
واستعادتها بالتأكيد نفسه، فتتحول الحالة الحالية إلى نسخة الرجوع التالية.
بيانات الرجوع على الجهاز غير مشفرة، مثل قاعدة التطبيق نفسها؛ تشفير ملف
خارجي لا يشفّر قاعدة البيانات أو نسخة الرجوع. إذا التزم التخزين ثم تعذرت
إعادة التهيئة، تُعرض حالة «تمت الاستعادة» وإعادة الفتح بدل ادعاء أن
البيانات لم تتغير. شاشة القفل تتيح استعادة ملف موثوق كامل دون تصدير
البيانات الحالية؛ هذا ليس استردادًا للـPIN ولا فك تشفير قاعدة محلية.

## الملفات والتحقق

اجتازت المجموعة الكاملة **241 اختبارًا**، وأعيد فحص اختبارات المرحلة
الـ16 بعد إضافة نافذة الحفظ الأصلية وحدود كلمة المرور ومعالجة دورة حياة
نافذة الملفات. اجتاز Chrome **13 مجموعة فحص** بملفات منزلة حقيقية
وبدون أخطاء تشغيل أو طلبات موارد خارجية. نجح بناء الويب مع كاش 43
ملفًا محليًا. تشمل الأدلة `phase-11-browser-validation.json` وصور
الإعدادات وحوار PIN بالعربية الداكنة بعرض 390 بكسل.

نجح كذلك بناء Android release بعد إضافة منتقي الملفات، بحجم 65.1 MB
في مجلد البناء المحلي. هذا فحص توافق بناء، وليس تجربة نافذة النظام
على هاتف فعلي. لم تُستبدل نسخة سطح المكتب ولم يُنشر APK جديد خارجيًا.

فحص المنصات الأصلية هنا يقتصر على البناء واختبارات دورة الحياة المحاكاة؛
لم تُجرّب نافذة اختيار/حفظ الملفات على هاتف فعلي، ولا تُدّعى حماية عتادية
أو تشفير شامل لتخزين التطبيق.

- `lib/features/security/`: قفل الجلسة وPBKDF2 للرمز وحوارات الأمان.
- `lib/core/security/password_crypto.dart`: عشوائية آمنة واشتقاق مفاتيح.
- `lib/features/backup/`: صيغة الملف والتشفير والفحص المؤقت والاستبدال
  الذري والرجوع والواجهة واختيار الملفات.
- إعدادات الخصوصية وتدفق المحافظ والتهيئة والملاح والشريط وبوابة التطبيق
  ودورة حياة الاشتراكات، مع ترقية علامة قاعدة البيانات إلى 11.
- `test/backup/`: نسخ/تشفير/تلف/توافق/علاقات/انقطاع/إعادة فتح ملف قاعدة
  حقيقي وإيصالات ثابتة وخصوصية وPIN وواجهة عربية ضيقة.
- `tool/security_browser_smoke.cjs`: Chrome معزول ببيانات اختبار عبر
  الواجهة، وتنزيل ملفات فعلية واستعادتها وقفل وإخفاء وعمل دون إنترنت.

الفرع `feature/settings-security-backup` بدأ من `main` عند `c5b65aa`
ثم أضيف أساس المرحلة العاشرة `80342d1`. لا رفع أو دمج في main دون طلب.
نسخة APK السابقة على سطح المكتب لا تُستبدل بهذه المرحلة.
