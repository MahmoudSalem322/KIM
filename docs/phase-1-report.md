# Kim — تقرير المرحلة الأولى

## المنجز

- مشروع Flutter Web ببنية Feature-First، مع Riverpod وGoRouter وSembast Web.
- ست صفحات قابلة للتنقل: الرئيسية والمحافظ والعمليات والميزانيات والتقارير والإعدادات.
- نظام تصميم موحد بألوان وخطوط محلية وأزرار وبطاقات وحقول وحوارات وتنقل متجاوب.
- العربية RTL والإنجليزية، وثيم الجهاز والفاتح والداكن.
- حفظ فعلي للإعدادات في IndexedDB، واستعادتها بعد إعادة التحميل مع مسار الصفحة.
- حسابات BigInt دقيقة، UUID، قاعدة بيانات بإصدار وترحيلات ومعاملات ذرية لمنع التكرار.
- نسخة ويب تضم جميع مواردها محليًا، مع كاش للعمل دون شبكة بعد أول تحميل كامل.
- إعادة تسمية التطبيق الظاهر وحزمة Dart إلى Kim وربطه بريبو KIM.

## الملفات

جميع الملفات جديدة لأن المشروع بدأ من الصفر. أهم المجموعات:

- pubspec.yaml وpubspec.lock وanalysis_options.yaml وassets/fonts: أساس المشروع والحزم والخطوط.
- lib/app وlib/main.dart: التهيئة والتطبيق والتنقل والهيكل المتجاوب.
- lib/core/domain: المال الدقيق ومعرفات العمليات.
- lib/core/data: التخزين المحلي والترحيلات ومنع تكرار العمليات.
- lib/core/l10n وlib/core/platform: الترجمة ولغة وثيقة المتصفح.
- lib/shared/design_system وlib/shared/widgets: الثيم والمكونات والحالات الفارغة.
- lib/features/settings: طبقات Domain وData وPresentation للإعدادات الفعلية.
- lib/features/{dashboard,wallets,transactions,budgets,reports}/presentation: الصفحات الأساسية فقط.
- web وtool: موارد ويب Kim وبناء الكاش وفحص المتصفح والحسابات على JavaScript.
- test: اختبارات الواجهة والإعدادات والمال والتخزين.
- README.md وAGENTS.md وdocs: تعليمات التشغيل وقواعد التطوير والتقرير وخريطة الفروع والصور.

## التحقق

- Flutter 3.47.2 / Dart 3.13.2.
- flutter analyze: لا توجد أخطاء أو تحذيرات تحليل.
- flutter test: نجحت 19 حالة اختبار.
- flutter build web --release --no-web-resources-cdn --pwa-strategy=none: نجح البناء.
- Chrome: حفظ اللغة والثيم والمسار بعد إعادة التحميل، وإعادة تحميل دون شبكة والتنقل.
- الكاش يضم 42 ملفًا محليًا. تقرير المتصفح التفصيلي في browser-validation.json.
- فحص JavaScript مستقل للحسابات والمعرفات: نجحت 7 حالات.
- فحص واجهة الهاتف العربية وواجهة سطح المكتب القصيرة، دون استثناءات متصفح أو طلبات خارجية.

مشغّل flutter test --platform chrome في SDK المحلي يفتقد ملفًا داخليًا؛ لذلك
استُخدم فحص Dart المترجم إلى JavaScript داخل Chrome، مع فحص التطبيق الحقيقي
باستخدام Playwright. تحذير إهمال خيار pwa-strategy من SDK لا يمنع البناء؛ الكاش
هنا مولد مستقلًا بواسطة tool/generate_offline.dart.

## الحدود

لم تبدأ المرحلة الثانية. المحافظ والدخل والمصاريف والميزانيات والتقارير صفحات
فارغة صادقة، وليست وظائف مالية مكتملة. الدعم المختبر هو Flutter Web على Chrome؛
لم تُختبر تطبيقات الهواتف الأصلية أو Firefox/Safari بعد.

أول زيارة تحتاج شبكة أو خادمًا محليًا، والعمل دون شبكة يحتاج اكتمال الكاش على
HTTPS أو localhost. مسح بيانات الموقع يحذف البيانات؛ لا توجد مزامنة أو نسخة
احتياطية في المرحلة الأولى. اسم قاعدة IndexedDB الداخلي بقي mywallet للمحافظة
على الإعدادات السابقة عند تغيير العلامة إلى Kim؛ الاسم الداخلي لا يظهر للمستخدم.
